# 分阶段实现路线图

## phase 0 - 硬件 环境 学习
目标：熟悉新编程环境 购买硬件 掌握不同插件用法

## Phase 1 — FPV 眼镜与云台联动
目标：验证头部追踪 → 云台同步的核心链路

搭建三轴云台（3个舵机）
读取 FPV 眼镜/外置 IMU 的姿态数据
无线发送角度 → 云台同步转动
里程碑：转头，云台跟着动

## Phase 2 — 手套遥控器设计与验证
目标：完成手套硬件 + 模式切换逻辑

手套结构：IMU + 摇杆 + 按键 集成
实现摇杆模式 / 机械臂模式状态机
拇指食指弯曲检测（弯曲传感器或 IMU 估算）
串口调试输出，验证数据正确性
里程碑：手套数据稳定可读，模式切换正确

## Phase 3 — 手套遥控小车（陆地通信验证）
目标：验证无线通信链路 + 手套控制逻辑

普通四驱小车底盘
手套摇杆控制前后左右
NRF24L01 / LoRa 无线通信
里程碑：手套稳定遥控小车行驶

### Phase 4 — 手套遥控小船（防水 + 水面驱动验证）
目标：验证防水方案与水上推进

简易船体（泡沫/3D打印）
水下推进器或舵面测试
电子仓防水密封验证
里程碑：游泳池内稳定遥控行驶

### Phase 5 — 机械臂原型
目标：验证手势 → 机械臂映射

3~4轴机械臂（防水舵机）
IMU 腕部姿态 → 机械臂角度映射
夹爪开合控制
机械臂回原位逻辑
里程碑：手臂动，机械臂同步动，回原位正常

### Phase 6 — 中继站原型机
目标：验证地面→水下通信链路

浮标外壳防水设计
电缆（B计划）接口与密封
信号中转测试（游泳池边缘 → 水下）
里程碑：信号稳定中转，无丢包

### Phase 7 — 简易潜水艇（实验型ROV）
目标：水下运动 + 摄像头回传 + 全链路联调

简化机身（亚克力管）
推进器 × 4（前进/偏航/升降）
摄像头 + FPV 回传
全系统联调：手套→中转→ROV→画面回传
里程碑：游泳池内完整演示

### Phase 8 — 完整体 ROV
目标：参赛级别完整系统

完整机身（PETG 3D打印）
双机械臂 + 三轴云台摄像头
力反馈手套（可选）
系统优化、外观完善、文档整理
里程碑：完整演示 + 参赛提交
