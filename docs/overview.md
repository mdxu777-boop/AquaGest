# Planning
## 原计划
AquaGest 是一套基于惯性传感器的遥控器姿态识别水下控制系统。用户用带有摇杆的手势识别手套，通过手势动作实时控制水下遥控载具的机械臂， 左摇杆控制浮潜，右手摇杆控制前后以及偏航，按下摇杆将同侧手套在摇杆/机械臂模式切换，机械臂模式用大拇指和食指控制机械臂的夹子开合，移动手臂机械臂同步移动，切换回摇杆模式机械臂自动回归原位，然后当侧手套重新获得相应控制权。用户使用fpv眼镜观察摄像头信息 摄像头云台会同步跟随眼镜倾斜，并可完成任务。
系统由三部分组成：地面控制端采集手部姿态与摇杆数据，通过无线模块发送指令；漂浮双向中转站（可以是无人船或者浮标）接收地面信号，（a计划，中转站将无线信号转换成声波信号发送给水下任务执行机器人）（b计划 使用光纤或电缆） 机器人通过中转站传递摄像头信号回来给接收端；水下载具端接收指令后驱动机械臂，推进器或舵面执行运动。
载具采用 3D打印制作，搭载摄像头实时回传水下画面，以及两个机械手臂，（（可选）可在手套端做实时的力反馈）并根据遥控器做动作完成任务。还有用fpv眼镜可以看到摄像头视角 摄像头将在透明塑料壳中并整个探出机体 可以观测到前方 左右 上下，fpv眼镜倾斜角度同步控制三轴云台倾斜（或者也可以换成鱼眼摄像头加监视器方案 但是fpv好想更酷一些）
目标用户是海洋研究者、水下生态监测者、以及教育场景中的学生群体。
分阶段实现fpv眼镜与云台 遥控手套设计 手套遥控小车（实验手套与通讯）手套遥控小船（实验防水与驱动）机械臂 中继站原型机 简易潜水艇（实验型 测试遥控中继等） （潜水艇完全体） 结束

## 项目概述
AquaGest 是一套基于惯性传感器的手势识别水下控制系统。用户佩戴集成摇杆的手势识别手套，通过手势动作实时控制水下遥控载具（ROV）的运动与机械臂操作，并通过FPV眼镜获得沉浸式第一视角画面。
定位：系统展示人机交互创新 + 水下作业能力，目标用户为海洋研究者、水下生态监测者及教育场景学生群体。

## 系统架构
[操作者]
  手势手套（IMU + 摇杆）+ FPV眼镜（头部追踪）
        ↓ 2.4GHz / LoRa 无线
[漂浮中转站]（浮标/无人船）
        ↓ A计划：声学调制解调器（未来拓展）
        ↓ B计划：防水电缆（游泳池）
[水下ROV]
  推进器 + 机械臂 + 三轴云台摄像头
        ↑ 视频信号回传 

## 手套控制映射
    左摇杆 上/下 ROV 上浮 / 下潜
    右摇杆 前/后 ROV 前进 / 后退
    右摇杆 左/右 ROV 偏航旋转
    按下左摇杆左手切换：摇杆模式 ↔ 机械臂模式
    按下右摇杆右手切换：摇杆模式 ↔ 机械臂模式

机械臂模式：
    拇指+食指开合控制夹爪开合机械臂模式：
    手臂整体移动机械臂同步跟随（IMU 读取腕部姿态）
    切回摇杆模式机械臂自动回归原位，该侧恢复摇杆控制

## FPV 云台联动
    FPV眼镜内置陀螺仪 → 读取俯仰/横滚/偏航角
    数据无线回传 → 控制ROV三轴云台同步转动
    摄像头置于透明亚克力球形罩内，视野覆盖前/左/右/上/下

## 硬件选型

### 控制端
    SP32ESP32 IMUMPU-6050 每只手套各一个摇杆PS2 摇杆模块含按压检测 无线NRF24L01 弹力手套 + 3D打印固定座

### 中转站（浮标）
    外壳3D打印+硅胶圈
    控制板ESP32电缆接口水密航插（M12/M16）供电锂电池组（3S）

### 水下ROV
主控 Raspberry Pi 4 + Arduino NanoPi 处理视频 Arduino 处理驱动
推进器 T100/T200 水下推力器（Blue Robotics）
机械臂 防水舵机 × 3~4 轴 MG996R 套硅胶密封 或 水下专用
摄像头 USB 广角摄像头 或 树莓派摄像头模块 置于透明球形罩
云台 防水微型舵机 × 3轴
防水 亚克力管 + 法兰密封端盖
机身3D 打印（PETG）

### FPV 方案
DJI Goggles 2 搭配 O3 图传，延迟极低画质好，但价格较高
经济方案：Fatshark 或 Eachine EV300D，模拟图传，延迟更低
头部追踪：头显内置 IMU（DJI自带）或外挂 OpenTrack + TrackIR

## 软件架构
控制端（ESP32）
 读取 IMU 姿态数据（I2C）
 读取摇杆数值（ADC）
 模式状态机（摇杆模式 / 机械臂模式）
 打包数据帧 → 无线发送

中转站（ESP32）
 接收无线数据
 转发至电缆（串口/以太网）

ROV端（Arduino Nano）
 接收指令帧
 解析：推进器PWM / 机械臂舵机角度 / 云台角度
 驱动输出

ROV端（Raspberry Pi）
 摄像头采集 → 视频编码 → 回传
